Jellyfin → Stremio

Each Jellyfin setup gets its own random link — like Torrentio. Enter your server details, generate the link, and install it in Stremio/Nuvio. Different servers/user setups = different links, all served by this one process.
Don't share your install link — it contains your server URL and API key. If friends want in, point them to the public configure page where they add their own Jellyfin.

Environment variables (JELLYFIN_URL / JELLYFIN_API_KEY) are set and take precedence at boot.
Applies only to NEWLY created setups — existing ones keep their own Proxy checkbox below
