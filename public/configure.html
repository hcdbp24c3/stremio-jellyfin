Connect your Jellyfin

This server turns your own Jellyfin library into a Stremio addon. Your server details go into a private install link — they are only ever yours.

Your URL and API key are never sent to anyone else — they are only embedded in your own install link.
Don't share your install link — it grants access to your Jellyfin library.
